# Mini-Pupper Mission Dashboard

A static HTML mockup of the real-time mission monitoring dashboard for the Mini-Pupper swarm exploration system.

---

## Overview

The dashboard provides a single-page view of robot health, live move telemetry, mission history, and AI-generated insights. It is designed to visualize data flowing through the full pipeline:

```
Maze App (SDL2)
    ↓  HTTPS POST /move
Logging Server (MongoDB · 10.170.8.101:8443)
    ↓  HTTPS POST /move
AI Server (Redis · 10.170.8.109:8443)
    ↓  RAG query
Dashboard (AI Insight panel)
```

---


## Dashboard Sections

### Robot Health (Sidebar)
Displays status, battery level, current mission, last heartbeat, and IP address for each active robot in the swarm. Currently shows **PUPPER-01**.

### Active Mission — Move Breakdown
Bar chart showing the distribution of movement commands (straight, left turn, right turn, reverse) for the current mission.

### AI RAG Insight
A natural-language summary generated by querying the vector database on the AI server. Compares the current mission against similar historical missions to surface anomalies or tuning recommendations.

### Stats Bar (top of main panel)
Six key metrics for the active session:

| Metric | Description |
|--------|-------------|
| Total Moves | Move commands sent this mission |
| Distance | Estimated distance traveled (units) |
| Duration | Elapsed mission time |
| Missions Run | Number of missions in this session |
| Success Rate | Percentage of missions that reached the goal |
| Robots Online | Active robots in the swarm |

### Live Move Telemetry
Scrollable table of the most recent move events pulled from MongoDB (`maze.moves_pupbyte1`) and Redis (`team1tt_pupbyte1`), showing sequence number, direction, position, goal status, and timestamp.

### Mission History
List of all past missions with result (SUCCESS / ABORTED / IN PROGRESS), duration, move counts, and distance.
