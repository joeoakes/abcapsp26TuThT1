# Mini Pupper AI Maze Solver Runbook

This runbook shows exactly how to run the full pipeline so Mini Pupper moves from AI decisions generated by `maze_brain`.

## Goal

Run these components together:

1. `maze_sdl2` (autoplay mode) asks the AI brain for next moves.
2. `maze_brain` returns actions (`UP`, `DOWN`, `LEFT`, `RIGHT`, `DONE`) and forwards them to Mini Pupper.
3. Mini Pupper listener receives each action and publishes ROS2 `/cmd_vel` commands.

---

## Machine Roles

- **AI Server**: `spark-f40d` at `10.170.8.109`
  - Runs `maze_brain` on port `8010`
- **Mini Pupper**: `ubuntu@10.170.8.209`
  - Runs listener stack (`ros_bridge` + `ros_bridge_node`)
- **Maze Client Host**: wherever you run `maze_sdl2`
  - Calls AI brain `/init` and `/next`

Keep this terminal open.


## Step 3: Run maze client in autoplay mode

On the host where `maze_sdl2` is built:

```bash
cd /path/to/abcapsp26TuThT1/maze
export MAZE_AUTOPLAY=1
export MAZE_BRAIN_INIT_URL=http://10.170.8.109:8010/init
export MAZE_BRAIN_NEXT_URL=http://10.170.8.109:8010/next
./maze_sdl2
```

Expected behavior:

- Maze app prints `Autoplay: ENABLED`
- AI init/next calls succeed
- Mini Pupper moves one step per AI action

## Motion tuning (to match virtual maze)

Set these on Mini Pupper before starting listener:

```bash
MAZE_ACTION_MODE=grid_absolute \
MAZE_STEP_LINEAR=0.15 \
MAZE_STEP_ANGULAR=0.8 \
MAZE_TURN_90_DURATION=0.85 \
MAZE_CELL_MOVE_DURATION=0.60 \
bash robot/start_minipupper_listener.sh
```

Tune:

- `MAZE_TURN_90_DURATION` for accurate 90-degree turns
- `MAZE_CELL_MOVE_DURATION` for one-grid-cell forward distance

## Troubleshooting

- `AI init POST failed` / `AI next POST failed`:
  - Brain not reachable at configured `MAZE_BRAIN_*_URL`
  - Wrong port (use `8010` in this setup)
- `Published action ... to 0 subscriber(s)` on robot:
  - `ros_bridge_node.py` not running or ROS env not sourced
- `No module named uvicorn` on AI server:
  - Activate `.venv` and install dependencies there
- `No module named rag_memory`:
  - Use `PYTHONPATH=~/abcapsp26TuThT1/maze_brain` when launching uvicorn
